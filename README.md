# Digital Twin Bridge

Futuristic industrial AI landing page for hackathons, investor pitches, and product demos.

## Stack

- React 19 + Vite 8
- Tailwind CSS 4
- Framer Motion
- Recharts
- Lucide React
- ShadCN-style UI primitives

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build for production

```bash
npm run build
npm run preview
```

## Features

- **12 sections**: Hero, Problem, Market, AI Innovation, Architecture, Features, Stakeholders, Savings, SWOT, Business Model, Roadmap, CTA
- **Dark / Light mode** with smooth transitions (toggle in navbar)
- **Industrial imagery** via Unsplash (full-width backgrounds + section visuals)
- **Animated charts** (Recharts market & revenue visualizations)
- **Loading screen** and scroll-triggered animations
- **Fully responsive** mobile layout

## Hackathon tips

1. Start in **dark mode** for maximum visual impact on projectors.
2. Use navbar links to jump between sections during your pitch.
3. Highlight the **competitor comparison** and **AI pipeline** sections for judges.
4. Mention **₹8K prototype** and **zero recurring AI cost** from the hero stats and innovation section.
